# FlashCart Documentation Portal

> **Docs Portal** | Bilingual (Bangla/English) documentation, guides, and tutorials for FlashCart.

## About

Complete documentation for the FlashCart platform covering customer guides, partner setup walkthroughs, SEO optimization, notification setup, and FAQ. All content is available in both Bangla and English.

## Features

- Bilingual documentation (Bangla/English toggle)
- Full-text search across all docs
- Admin panel for content management (password protected)
- Syntax-highlighted code blocks
- Table of contents navigation
- Mobile-responsive layout
